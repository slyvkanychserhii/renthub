# RentHub  

RentHub is a web application for rental property management, developed using Django and Docker. The project allows users to manage users, listings, bookings, and reviews.  

## Features  

- **Modular Architecture**: The project is divided into multiple apps (users, listings, bookings, reviews), making maintenance and feature expansion easier.  
- **Docker Support**: Full support for containerization using Docker and Docker Compose for simplified deployment and dependency management.  
- **Security**: Environment variables are used to store sensitive information such as passwords and keys.  
- **Superuser Creation**: Automatic superuser creation on the first application launch, simplifying the initial setup.  
- **REST API**: A RESTful API is implemented using Django REST Framework, enabling easy integration with other services.  

## Technologies  

- **Programming Language**: Python  
- **Frameworks**: Django, Django REST Framework  
- **Database**: MySQL  
- **Containerization**: Docker
